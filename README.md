# TalentIQ — Backend

TalentIQ is a full-stack mock interview booking platform. Candidates book and pay for practice interviews with real professionals, attend them over live video, and receive structured feedback. The platform supports five distinct roles — Super Admin, Employee, Candidate, Recruiter, and Support — each with its own workflow, permissions, and dashboard.

**Live Frontend:** https://talentiq2-frontend2.onrender.com

**Frontend Repo:** https://github.com/Ayodhya-Rode/TalentIQ2-frontend

## Tech Stack

- **Runtime:** Node.js, Express.js
- **Database:** PostgreSQL, hosted on Neon
- **ORM:** Prisma
- **Auth:** JWT with separate access and refresh tokens, httpOnly refresh cookie, bcrypt password hashing
- **Scheduled Jobs:** node-cron

## Third-Party Services

| Service | Purpose |
|---|---|
| Razorpay | Candidate payments and refunds via the standard Payments API |
| LiveKit | Live video interview rooms with per-user access tokens |
| Brevo | Transactional emails — confirmations, reminders, cancellations, digests |
| ImageKit | Candidate resume file storage |
| Cloudflare R2 | Interview recording storage (S3-compatible) |

## Roles & Core Features

### Super Admin
- Approves or rejects pending registrations across all roles
- Creates and manages interview categories
- Views platform-wide dashboard: pending approvals, active/rejected accounts by role, total categories, completed interviews, platform revenue
- Monitors employees who've hit their monthly cancellation/postponement limit
- Creates Support accounts directly, with an auto-generated password emailed to the new account
- Receives a daily 6 PM digest email summarizing total, solved, and pending support queries

### Employee
- Creates and edits a profile with education, skills, experience, company, designation, and interview categories (supports multiple categories per employee)
- Creates individual availability slots or marks an entire day unavailable in one action, without affecting already-booked slots
- Views all bookings with candidate details and their uploaded resume
- Confirms interview completion (only after the slot's start time, expiring 24 hours after the slot's end time if not confirmed)
- Submits feedback and a 1–10 score after an interview is completed — locked once submitted
- Cancels or postpones a confirmed booking, capped at 3 combined actions per calendar month; the 4th attempt is blocked and logged for Super Admin review
- Joins live interview rooms, restricted to the 10-minute window before the scheduled start time

### Candidate
- Creates and edits a profile with education, skills, location, designation, projects, and certificates
- Uploads an optional PDF resume (ImageKit-hosted, 5MB limit)
- Browses employees by interview category and books an available slot within the next 7 days
- Pays via Razorpay; payment is verified server-side against Razorpay's own payment record before confirming the booking
- Capped at 3 bookings per week with the same employee
- Confirms interview completion from their side
- If an employee cancels, can either rebook the same employee on a different slot at no extra cost, or request a real Razorpay refund
- Views received interview feedback and score per completed booking
- Joins live interview rooms within the same 10-minute pre-interview window

### Recruiter
- Creates a profile with company and location
- Searches and browses approved candidate profiles by skill or designation
- Sends outreach emails to candidates with a specific role and required skills, generated from a template using their own profile details
- Sees a soft warning if a candidate was already contacted recently, without being blocked from sending again
- Views a full history of every outreach email sent

### Support
- Account created and password auto-generated by Super Admin, delivered via email with a login link
- Changes their own password from the dashboard
- Views and manages queries raised by candidates, employees, and recruiters
- Dashboard shows total, solved, and pending query counts

## Booking & Payment Safeguards

- Slots are locked atomically at the moment a payment order is created, preventing two candidates from booking the same slot
- A scheduled job runs every 5 minutes to detect abandoned checkouts — before releasing a stale slot, it re-verifies with Razorpay directly, and force-confirms the booking instead of deleting it if payment actually went through
- Refunds are processed through Razorpay's real refund API, not just marked as pending
- All monetary amounts, booking windows, and cancellation limits are enforced server-side, not just in the UI

## Live Interviews

- Each confirmed booking gets a deterministic LiveKit room, generated from the booking ID
- Join tokens are issued only to the actual candidate or employee on that specific booking, verified server-side against booking ownership
- Joining is only permitted from 10 minutes before the scheduled start time through the scheduled end time
- A reminder email is sent 10 minutes before the interview with a direct join link

## Setup

Clone and install dependencies:

\`\`\`bash

git clone https://github.com/Ayodhya-Rode/TalentIQ-2.git

cd TalentIQ-2

npm install
\`\`\`

Create a `.env` file with the following variables:

\`\`\` env
- DATABASE_URL=
- JWT_SECRET_ACCESS=
- JWT_SECRET_REFRESH=
- RAZORPAY_KEY_ID=
- RAZORPAY_KEY_SECRET=
- LIVEKIT_API_KEY=
- LIVEKIT_API_SECRET=
- LIVEKIT_URL=
- BREVO_API_KEY=
- IMAGEKIT_PUBLIC_KEY=
- IMAGEKIT_PRIVATE_KEY=
- IMAGEKIT_URL_ENDPOINT=
- FRONTEND_URL=
- NODE_ENV=development

\`\`\`

Run migrations and start the server:

\`\`\`bash

npx prisma migrate dev

npm run dev

\`\`\`

Server runs on `http://localhost:5000`.

## Scheduled Jobs

- **Interview reminder** — runs every minute, emails both parties 10 minutes before a confirmed interview
- **Stale payment sweep** — runs every 5 minutes, resolves abandoned checkouts
- **Support digest** — runs daily at 6 PM IST, emails Super Admin a support query summary
